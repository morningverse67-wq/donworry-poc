# 돈 워리 (DonWorry) PoC

예전에 든 보험이 지금 **무엇을, 몇 살까지** 보장하는지 한 화면에서 보여주는 서비스의 PoC입니다. 대상은 50~60대와 부모님 보험을 대신 확인하는 자녀입니다. 팀 과제로 만들었습니다.

**데모:** https://morningverse67-wq.github.io/donworry-poc/

## 화면
- **홈 → 내 보험 불러오기 → 결과:** 암·입원·치매 같은 일이 생겼을 때 받는 금액과 보장이 끝나는 나이, 앞으로 오를 보험료를 보여줍니다. 예를 들어 암보험이 80세에 끝나면 81세 이후는 비어 있다고 표시합니다.
- **부모님 보험 알아보기:** 자녀가 대신 확인하는 흐름입니다.
- **설계사 상담 도구:** 설계사가 고객 옆에서 같이 보는 화면입니다(공개 저장소에는 운영 목표 페이지를 넣지 않았습니다).
- **여행자보험:** 같은 기준으로 만든 보조 화면입니다.

## 실행
`index.html` 하나로 동작합니다. 외부 라이브러리나 서버가 없어서 브라우저로 열면 됩니다.

## 기획 과정
- **방향 전환:** 처음에는 새 보험 추천이었습니다. "나이가 들면 새로 가입하기 어렵다"는 피드백을 듣고 이미 가진 보험을 확인하는 쪽으로 바꿨습니다.
- **수익 모델:** 설계사가 쓰는 상담 도구의 월 구독료입니다. 소비자는 무료이고, 보험 판매 수수료는 받지 않습니다.

## 알아둘 것
- 화면의 보험과 고객은 모두 **데모 데이터**입니다. 실제 보험 상품, 약관, 가입 조건이 아니며 보험 가입을 권하지 않습니다.
- 페르소나 얼굴 사진(`docs/persona-kim.jpg`, `docs/persona-lee.jpg`)은 AI로 생성한 이미지입니다. 실존 인물이 아닙니다.
